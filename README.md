
# AppInitDev Knowledge MCP

Servidor MCP oficial de AppInitDev para consultar
aplicaciones Android, información del desarrollador,
redes sociales y recursos técnicos públicos.

## Servidor remoto

https://appinitdev-mcp.dev-appinitdev.workers.dev/mcp

## Sitio oficial

https://appinitdev.com/mcp/

## Funcionalidades

- Buscar aplicaciones Android.
- Consultar fichas y enlaces de Google Play.
- Obtener la identidad pública de AppInitDev.
- Consultar redes sociales.
- Buscar artículos, guías y tutoriales.
- Explorar relaciones entre aplicaciones y contenidos.

## Protocolo

Model Context Protocol (MCP).
Servidor remoto basado en Cloudflare Workers.

## Registro oficial

Identificador: com.appinitdev/knowledge

## Seguridad

Herramientas públicas de solo lectura.
No requiere acceso privado a Google Play Console.
